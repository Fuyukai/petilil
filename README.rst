Petilil
=======

A companion mod to `Liligant <https://github.com/Fuyukai/Liligant>`_ but for mixing in to mods.

This ain't for you.

Features
--------

A non-exhaustive list of all the features this adds, segregated by mods.

Recycling (GTCEu)
~~~~~~~~~~~~~~~~~

For various unknown reasons, KJS tweakers can't remove recycling recipes anymore. This presents
a problem for me because I replace all of the machine materials and the recycling recipes aren't
updated. Petilil simply prevents registration of recycling recipes for any machine blocks.
